## 🔧 적용된 기술

### 데이터 증강 기법
1. **문장 단위 분할**: 긴 문서를 문장 단위로 나누어 더 많은 샘플 생성
2. **엔티티 교체**: 전화번호, 날짜 등을 다른 값으로 교체하여 변형 생성
3. **OCR 노이즈 시뮬레이션**: 실제 OCR 오류를 시뮬레이션하여 강건성 향상
4. **템플릿 기반 생성**: 실제 문서 패턴을 템플릿화하여 대량 샘플 생성
5. **동의어 치환**: 한국어 동의어를 사용한 문장 변형
6. **샘플 조합**: 여러 샘플을 조합하여 새로운 복잡한 문서 생성
7. **역번역 시뮬레이션**: 조사 변경 등을 통한 자연어 변형
8. **다단락 문서**: 실제 계약서와 유사한 다단락 문서 생성

### 데이터 품질 관리
- BIO 태깅 정확성 보장
- 중복 태깅 방지 로직 적용
- 엔티티 타입별 균형 유지
- 무작위 샘플 섞기로 학습 효과 극대화
