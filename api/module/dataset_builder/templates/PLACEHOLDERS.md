# Contract template — placeholder → manifest mapping

Template: `저작재산권_이용허락_계약서_template.md`. Two kinds of placeholders:

## A. Direct substitution (copied verbatim from the manifest column)

| Placeholder | Manifest column | If blank → |
|---|---|---|
| `{{저작권자명}}` | 저작권자명 | (always present — real names) |
| `{{저작권자소속}}` | 저작권자 소속 | "(소속 미상)" |
| `{{공동저작자}}` | 공동저작자 | "(해당 없음)" |
| `{{저작물명}}` | 제목 | (always present) |
| `{{저작물유형}}` | 정보유형 (fallback 분류) | use 분류 |
| `{{식별번호}}` | 원문인덱스 | — |
| `{{원본파일명}}` | 원본파일명 | "(파일명 미상)" |
| `{{언어}}` | 언어 | "한국어" (default) |
| `{{제작일자}}` | 제작일자 | "(미상)" |
| `{{공표일자}}` | 공표일자 | "(미상)" |
| `{{주제어}}` | 주제어 | "(없음)" |
| `{{원본소유자}}` | 원본소유자 | — |
| `{{이용자명}}` | — (CONFIG, default e.g. "한국문화정보원") | configurable per run |
| `{{작성일}}` | — (generation date, passed in) | today |

## B. Computed by the generator (NOT a raw column)

| Placeholder | Computed from | Logic |
|---|---|---|
| `{{공공누리유형표시}}` | 공공누리 유형 (0–4, 9 already→0) | `"제" + code + "유형"` → 제0유형 … 제4유형 |
| `{{이용허락_권리범위}}` | 복제권, 저작재산권 공연권, 공중송신권, 저작재산권 전시권, 저작재산권 배포권, 대여권, 2차적저작물 작성권 | numbered list of the rights whose flag = Y (e.g. "1. 복제권\n2. 공중송신권\n3. 전시권"). If none → "별도 협의에 따른다." |
| `{{상업적이용_조항}}` | 상업적이용허락 | 가능→"상업적 이용을 허락한다." / 금지·불가→"상업적 이용을 금지한다." / blank·'-'→"상업적 이용 여부는 별도 협의에 따른다." |
| `{{2차적저작물_조항}}` | 2차적저작물 작성권 | Y→"2차적저작물의 작성을 허락한다." / N→"2차적저작물의 작성을 허락하지 아니한다." |
| `{{유효기간_조항}}` | 계약상 유효기간 → 저작권 만료일 → boilerplate | if 계약상유효기간: "본 계약의 이용허락 기간은 {값}으로 한다." elif 저작권만료일: "본 저작물의 저작권 존속기간({만료일}까지) 동안 유효하다." else: "별도의 정함이 없는 한, 저작권법상 저작재산권 보호기간 동안 유효하다." |
| `{{저작인접권_조항}}` | 저작인접권자 | present→"저작인접권자({값})의 권리가 존재하며, 그 처리 책임은 갑에게 있다." / blank→"해당 사항 없음." |
| `{{초상권_조항}}` | 초상권 | "해당"→"본 저작물에 초상이 포함되어 있어, 촬영 동의 및 초상권 분쟁에 대한 책임은 갑에게 있다." / else→"해당 사항 없음." |

## C. Synthetic PII (generated by `synthetic_identity.py` — all fake, seeded by 원문인덱스)

갑 keeps the **real** 저작권자명/소속 (manifest) + a synthetic 담당자 contact; 을 is fully synthetic (≈55% 법인 / 45% 개인).

| Placeholder | Source | Notes |
|---|---|---|
| `{{갑_담당자}}` / `{{갑_부서}}` / `{{갑_직급}}` | `make_licensor_contact` | synthetic managing-contact person for the real 저작권자 |
| `{{갑_연락처}}` / `{{갑_이메일}}` / `{{갑_주소}}` | `make_licensor_contact` | 010-…, email, address |
| `{{갑_사업자등록번호}}` | `make_licensor_contact` | only if 갑 is an institution (checksum-valid fake); else blank |
| `{{을_유형}}` | `make_licensee` | "법인" or "개인" |
| `{{이용자명}}` | `make_licensee` | company name (법인) or person name (개인) |
| `{{을_대표자}}` | `make_licensee` | 법인 only |
| `{{을_사업자등록번호}}` | `make_licensee` | 법인 only — checksum-valid fake |
| `{{을_주민등록번호}}` / `{{을_생년월일}}` | `make_licensee` | 개인 only — fake (Faker ssn) |
| `{{을_전화}}` / `{{을_휴대폰}}` / `{{을_이메일}}` / `{{을_주소}}` | `make_licensee` | contact |

All ID numbers (주민등록번호·사업자등록번호) are **format-valid fakes** for synthetic training data — unrelated to any real person/entity.

## Notes for validation
- All 9 mandatory **rights** elements map into 제3조/제4조/제6조/제7조 (권리범위·상업적이용·2차적저작물·유효기간·저작인접권·초상권·출처표시/공공누리유형).
- 8 **work-info** elements → 제2조 table. 3 **author** elements → 전문 + 서명란 (저작권자·소속·공동저작자).
- `{{이용자명}}` ("을") has no source column — it's a run-level config (the using party). Default suggested: "한국문화정보원" (the 수요기관) or left as "(이용자)".
- `공공누리 제0유형` works (별도 이용허락 대상) are the natural fit for this license-grant contract.
