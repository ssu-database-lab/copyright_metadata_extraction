## 🎯 핵심 인사이트

### 왜 혼합 데이터가 필요한가?

```
시나리오: email 어댑터가 address만으로 학습한 경우

입력 샘플: "주소는 서울입니다"
- email 어댑터는 이 데이터를 본 적 없음
- 하지만 학습 데이터에는 "서울"이 있었을 수도 있음
- 만약 있었다면? → 이메일로 오분류 가능!

반대로: email 어댑터가 혼합 데이터로 학습한 경우

입력 샘플: "주소는 서울입니다"
- email 어댑터는 주소 문맥을 학습했음
- "주소는"이라는 문맥 → address 신호
- 결과: 낮은 신뢰도로 B-email 예측 가능 → 앙상블이 address 선택

✅ 문맥 학습 = 정확한 판별 가능!
```
