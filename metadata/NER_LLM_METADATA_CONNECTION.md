# NER / LLM Metadata Contract

This document is the product-side mapping between the clean extraction schema
and the final 50-column metadata export schema. Historical research notes,
source-audit details, and label-decision history were moved to
`../paper/docs/`.

Source of truth for executable schema constants:

- `module/parts/labels.py`

## Clean Schema

The product clean schema is a **disjoint 3-way split of 35 labels**:

- 9 REGEX labels — strict surface format (`regex.py` `PATTERNS`).
- 17 NER labels — free-form Korean spans (BERT token classification).
- 9 LLM-delegated labels — policy / context judgment (stub).

`copyright_entitle` is generated by the LLM/export stage and is not part of
`ALL_LABELS`.

## Pipeline

```text
document text
  |
  v
regex extraction
  |-- 9 strict-format labels: phone, email, copyright_url, copyright_uci,
  |   date, ri_money, copyright_num, copyright_idnum, copyright_quantity
  v
NER extraction
  |-- 17 role-free free-form span labels (BERT BIO classifier)
  v
LLM/export stage
  |-- 9 delegated labels
  |-- route 7 role-free author attributes (5 from NER + email/phone) to
  |   ch_co / ch_ja / ch_nr fields
  |-- generate copyright_entitle
  v
50-column xlsx-compatible metadata output
```

## Arithmetic

Source labels: 9 REGEX + 17 NER + 9 LLM = 35 clean labels.

Final xlsx fields:

- 7 role-free author labels expand into 21 role-prefixed fields
  (`ch_co_*`, `ch_ja_*`, `ch_nr_*`).
- `date` is exported as `copyright_date`.
- `copyright_entitle` is generated separately by the LLM/export stage.

Total: **50 xlsx fields** = 35 clean labels − 7 role-free author labels
(unprefixed) + 21 role-prefixed expansions + 1 `copyright_entitle`.

## Export Procedure

```text
1. Run regex extraction for strict-format labels.
2. Run NER for the 17 clean span labels.
3. Merge regex and NER values into the clean schema.
4. Rename `date` to `copyright_date` for export.
5. Use the LLM/export stage to:
   - fill the 9 delegated labels,
   - route author attributes into ch_co / ch_ja / ch_nr,
   - generate `copyright_entitle`.
6. Emit the 50 xlsx-compatible fields.
```

## Consistency Checks

`module/parts/labels.py` should keep these invariants true:

```text
REGEX_LABEL_SET union NER_LABEL_SET union LLM_DELEGATED_LABEL_SET == ALL_LABELS
REGEX_LABEL_SET intersection NER_LABEL_SET == empty
REGEX_LABEL_SET intersection LLM_DELEGATED_LABEL_SET == empty
NER_LABEL_SET intersection LLM_DELEGATED_LABEL_SET == empty
copyright_entitle not in ALL_LABELS
```
