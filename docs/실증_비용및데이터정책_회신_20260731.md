> **실증 대상에 영상 저작물이 포함될 예정이라면 별도 개발이 선행되어야 하므로, 무하유 측과 대상 저작물 유형을 먼저 확정해 주시기를 요청드립니다.**

## 2. 비용 산정 방법 (요청하신 방법론 기재)

추정치를 사용하지 않고, **공식 공개단가 × 실측 토큰 사용량**으로 산정했습니다.

### 2-1. 단가 — 벤더 공식 문서

| 모델 | 담당 | 입력 $/1M토큰 | 출력 $/1M토큰 | 출처 |
|---|---|---|---|---|
| qwen3-vl-235b-a22b-instruct | OCR | $0.40 | $1.60 | Alibaba Model Studio 공식 단가표 (2026-07-15 갱신) |
| qwen3.5-122b-a10b | 추출·통합검증 | $0.40 | $3.20 | 동일 |
| google/gemma-4-31b-it | 이미지 VLM | $0.10 | $0.34 | OpenRouter 모델 페이지/API |

- 적용 리전: **싱가포르(International)** — 현재 사용 중인 엔드포인트 기준
- OpenRouter 카드 결제 수수료 5.5% 반영
- 환율 $1 = ₩1,400

### 2-2. 토큰 사용량 — 실제 파이프라인 계측

실제 문서를 파이프라인에 투입하고, **API 응답의 `usage` 필드를 수집**하여 단계별 토큰 사용량을 측정했습니다.

| 단계 | 모델 | 호출 | 입력 토큰 | 출력 토큰 |
|---|---|---|---|---|
| OCR | qwen3-vl-235b | 페이지당 1회 | **2,101/페이지** | 695/페이지 |
| 추출 | qwen3.5-122b | 문서당 1회 | **4,045 고정 + 558/페이지** | 1,782 |
| 통합검증(문서) | qwen3.5-122b | 문서당 1회 | 4,355 | **7,176** |
| VLM | gemma-4-31b-it | 이미지당 1회 | 789 | 218 |
| 통합검증(이미지) | qwen3.5-122b | 이미지당 1회 | 1,300 | **7,731** |

- 측정 대상: 실제 저작물양도계약서(4페이지) 및 저작물 이미지 1장
- 추출 단계의 고정/가변 분리는 입력 텍스트 길이를 달리한 3회 측정으로 별도 확인 (텍스트 없음 4,045 → 1페이지 4,654 → 4페이지 6,277)

### 2-3. 산정식

비용은 **페이지 수와 문서 건수 두 변수**로 결정됩니다. OCR은 페이지마다 발생하지만, 추출·통합검증은 **문서 1건당 1회만** 발생합니다.

> **비용 = ₩3.05 × 페이지 수 + ₩44.8 × 문서 건수**
> (+ 저작물 이미지 1장당 ₩35.6)

**검증:** 실측한 4페이지 문서 1건의 실제 비용 $0.04069 대비, 산정식 결과 $0.04073 → **오차 0.1%**

### 2-4. 산정 시 유의사항

- **API 비용은 사용량 종량제이며 상한이 없습니다.** 처리 물량이 늘면 비례하여 증가합니다.
- **사용자 수는 비용에 직접 영향을 주지 않습니다.** 1명이 50건을 처리하든 5명이 각 10건을 처리하든 동일합니다. 비용은 **처리 물량**에만 비례합니다.
- 위 금액은 **API 사용료만**이며, **서버 임대 비용은 별도**입니다(현재는 기존 VM 재사용으로 추가 비용 없음).
- 재시도·오류 발생 시 해당 호출분이 추가되므로, 실제 청구액은 위 산정치의 **약 105~110%** 를 예상하시는 것이 안전합니다.

## 3. 상용 API 데이터 정책 확인 결과

### 3-1. 종합

| 확인 항목 | ①②④ Alibaba Model Studio | ⑤ OpenRouter (Gemma) | ③ NER |
|---|---|---|---|
| **외부 전송 여부** | **전송됨** — 싱가포르 리전 저장 | **전송됨** — 미국 + 제3자 프로바이더 | **전송 없음** (로컬 CPU) |
| **처리 국가 특정** | 저장=싱가포르 명시. 추론=**중국 본토 제외 글로벌 노드**(제3국 가능) | ❌ **국가 특정 불가** (EU 전용 옵션 외 보장 없음) | 해당 없음 |
| **학습 활용** | ✅ **미사용** (계약 명문) | OpenRouter 자체 미사용 / ⚠️ **하위 프로바이더 기본값 = 학습 허용** | 해당 없음 |
| **보관 기간** | ⚠️ 저장 사실은 명시, **구체적 기간 미공개** | 기본 미저장(로깅 옵트인) | 해당 없음 |
| **DPA 제공** | ✅ 회원약관에 자동 편입 | ✅ 공개 / ⚠️ **민감정보 처리는 기본 배제** | 해당 없음 |

### 3-2. Alibaba Model Studio (OCR·추출·통합검증)

**학습 활용 — 사용하지 않음 (근거 강함)**

> "Alibaba Cloud will not use your Member Content to develop or improve the models on Model Studio, **unless you separately provide your consent**."
> — Product Terms §4.48(e)

동의하지 않는 한 사용하지 않는 **opt-in 구조**이므로, 별도로 비활성화할 설정이 없습니다. 기술문서에도 "will never use your data for model training"으로 재확인됩니다.

**데이터 위치 — 기술문서와 계약서가 불일치 (주의)**

- 기술문서: 싱가포르 리전 = 저장 싱가포르, 추론은 **"중국 본토를 제외한 글로벌 노드"**. 즉 중국 경유는 배제되나 **제3국(EU·미국·일본 등) 노드에서 연산될 수 있습니다.**
- 계약서(Product Terms §4.48(g)(viii)): 국가를 특정하지 않는 광범위한 국외이전 조항이 있으며, §4.48(g)(vii)은 **준거법 준수를 포함한 모든 보증을 명시적으로 배제**합니다.

→ **"중국으로 이전되지 않는다"를 공공기관에 보증하려면 벤더의 서면 확인서 또는 계약 특약이 필요합니다.** 표준약관만으로는 불충분합니다.

**보관 기간 — 확인 불가**

저장 사실은 공식 FAQ에 명시되어 있으나("will store data generated from model and application calls"), **API 입출력의 구체적 보관 일수는 어떤 공식 문서에도 없습니다.** 모니터링 데이터 30일만 명시. → **계약 전 서면 질의 필요.**

**개인정보 책임 소재 — 우리 측 100%**

> "You represent and warrant that **you have obtained the necessary consents from relevant individuals** … in relation to Member Content"
> — Product Terms §4.48(b)

우리가 개인정보처리자(controller), Alibaba가 수탁자(processor)입니다. **정보주체 동의 확보 책임은 전적으로 우리 측에 있음이 계약에 명시**되어 있습니다.

### 3-3. OpenRouter (이미지 VLM) — ⚠️ 즉시 조치 필요

**하위 프로바이더의 학습 활용이 기본 허용 상태입니다.**

> `data_collection` — **Default `"allow"`**
> "**allow**: (default) allow providers which store user data non-transiently and **may train on it**"
> — Provider Routing 공식 문서

> "OpenRouter **cannot control Model Provider-side training** once user data is transmitted to a training-permitted Model Provider."
> — Privacy Policy §4

**현재 저희 코드는 이 설정을 지정하지 않아 기본값(허용) 상태입니다.** → §5의 조치 필요.

**처리 국가를 특정할 수 없습니다.** 프로바이더 회사는 `provider.only`로 고정 가능하나, **국가 단위 보장은 EU 전용 옵션 외에 제공되지 않습니다.** 공공 실증 심사에서 지적될 가능성이 높습니다.

**민감정보는 DPA에서 기본 배제**되어 있어, 주민등록번호가 포함된 문서 전송은 계약 위반 소지가 있습니다.

**옵트아웃 불가 항목 1건**: 프롬프트 표본이 분류 목적으로 별도 모델에 전송됩니다(저장은 안 함, 익명 처리). 사용 자체가 동의로 간주되어 거부할 수 없으므로, 실증 신고 시 기재가 필요합니다.

## 4. 개인정보 법적 검토 — 실제 계약서 사용 시

> 아래는 공개된 법령·가이드라인에 근거한 기술적 검토이며, **최종 판단은 법무 검토를 받으시기를 권고드립니다.**

### 4-1. 핵심 결론

**현재 구성 그대로 주민등록번호가 포함된 실제 계약서를 전송하면 개인정보보호법 위반입니다.**

국외이전(제28조의8) 요건을 따지기 이전에, **주민등록번호 처리 자체(제24조의2)** 에서 먼저 제한됩니다. 그리고 이 제한은 **정보주체 동의로도 해소되지 않습니다.**

참고로, 2025년 발효된 EU 30개국 적정성 인정(한국 최고 수준의 국외이전 허용 경로)에서도 **주민등록번호는 명시적으로 제외**되었습니다.

### 4-2. 국외이전 규제의 적용

개인정보보호법 제28조의8 제1항은 **"제공·처리위탁·보관"** 은 물론 **"조회되는 경우"까지 모두 "이전"으로 규정**합니다.
→ "우리는 저장하지 않고 API 호출만 한다"는 논리는 성립하지 않으며, API 호출은 명백한 국외이전에 해당합니다.

적용 가능한 예외는 사실상 **제1호(정보주체의 별도 동의)** 뿐입니다. 나머지(법률 규정, 계약 이행, 인증, 적정성 결정)는 본 실증에 적용되지 않습니다.

### 4-3. 동의를 받을 경우 고지 필수 5개 항목 (제28조의8 제2항)

| 고지 항목 | 실증 시 기재 내용 |
|---|---|
| 1. 이전되는 개인정보 항목 | 계약서 이미지·OCR 텍스트에 포함된 성명, 생년월일, 주소, 연락처, 서명 (**주민등록번호는 마스킹 후 제외**) |
| 2. 이전 국가·시기·방법 | 싱가포르(문서 처리 시, HTTPS) / 미국(이미지 분석 시, HTTPS) |
| 3. 이전받는 자 | Alibaba Cloud (Singapore) Private Ltd. / OpenRouter, Inc. — 각 연락처 |
| 4. 이용목적·보유기간 | 목적: OCR·메타데이터 추출 연산 (학습 이용 금지) / 보유기간: 사업자 공식 정책상 기간 |
| 5. 거부 방법·절차·효과 | 거부 시 해당 문서는 실증 대상에서 제외, 불이익 없음 |

**유의:** ① 다른 동의와 **분리하여 별도로** 받아야 합니다(제22조). ② 사업자·국가가 변경되면 재고지·재동의가 필요하므로, **폴백 체인상 발동 가능한 모든 사업자·국가를 처음부터 열거**해야 합니다.

### 5-2. 대안 검토 (근본적 해소안)

주민등록번호 마스킹과 동의 절차가 부담스러운 경우, **국내 처리 서비스로 전환**하면 국외이전 문제 자체가 소멸합니다.

| 대안 | 국내 처리 | 학습 미사용 | 공공 조달 | 비고 |
|---|---|---|---|---|
| **네이버클라우드 (공공)** | ✅ 명시(평촌 IDC) | ⚠️ 개별 약관 서면 확인 필요 | ✅ **CSAP·ISMS-P 보유, 디지털서비스몰 등록** | 멀티모달(HCX-005) 보유 → 이미지 분석도 대체 가능 |
| 업스테이지 (SaaS) | ❌ 미국(AWS/Azure) | ✅ 약관 명문 | ❌ CSAP 미보유 | **온프레미스 배포 시에만** 국내 처리 |
| Google/Azure 서울 리전 | ✅ 리전 지정 | 별도 확인 | ⚠️ **CSAP '하' 등급** = 개인정보 미포함 시스템용 → **등급 미달** | |

> **비용 영향은 크지 않습니다.** 앞선 검토에서 국내 벤더 전환 시 비용이 오히려 소폭 저렴했습니다(§1 대비 유사 수준).

### 5-3. 참고 — 비용 최적화 여지

현재 비용의 **73%가 통합검증 단계**입니다(계약서 36.2% + 저작물 37.0%). 특히 저작물 이미지의 통합검증은 NER 결과가 없어 실질적으로 중재할 대상이 없는데도 전체 필드를 재생성하고 있습니다.
→ 이 부분을 최적화하면 **1,000건 기준 ₩95,654 → 약 ₩60,000 수준**으로 절감 가능합니다. 위 산정치는 **현 구현 기준의 상한값**으로 보시면 됩니다.
