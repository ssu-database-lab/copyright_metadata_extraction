**참고 — 시험용 데이터 구성**

권리유형별 1,000건은 두 출처를 합쳐 구성합니다.

| 권리유형 | 출처 | 확보 현황 |
|---|---|---|
| 만료저작물 | 공유마당(gongu.copyright.or.kr) | 1,505건 |
| 기증저작물 | 공유마당 | 1,050건 |
| CCL | 공유마당 | 1,779건 |
| KOGL | 공유마당 + KOGL 원문 메타데이터(143,946건) | 500건 — **500건 보충 필요** |

정답 라벨은 각 출처의 기존 메타데이터(제목·저작권자·라이선스코드·요약정보)를 활용하되,
`요약정보` 일부 레코드가 시각 설명이 아닌 **기증 행정정보**이므로 정답셋 구축 시 필터링합니다.
해상도·파일크기·파일포맷은 파일에서 결정적으로 산출되므로 별도 라벨링이 불필요합니다.

⚠️ **사전 협의 필요 사항**
1. 시험 입력이 **저작물 파일 단독**인지, 원본 메타데이터(제목·저작권자·라이선스)를 동봉하는지.
   파일 단독이면 11속성 중 제목·저자·라이선스 3종이 구조적으로 미채움이 되어 최대 72.7%로 제한됩니다.
2. `파일 생성 날짜`의 정답 기준 — EXIF/컨테이너 태그가 없는 파일은 원본 등록일 기준으로 채점.
