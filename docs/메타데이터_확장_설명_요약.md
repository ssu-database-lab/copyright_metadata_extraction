# 메타데이터 확장 항목 설명 (요약)

**작성자:** 숭실대학교 DB연구실 | **작성일:** 2026-03-20

---

## 확장 배경

프로젝트 초기 정의된 **표준 메타데이터 20개 항목**을 기준으로 시스템을 개발하였습니다. 그러나 실제 데이터셋의 문서(계약서, 동의서, 양도동의서 등)를 분석한 결과, 원본 20개 항목만으로는 문서 내 중요 정보를 충분히 추출할 수 없어 **36개 항목을 추가**하였습니다.

현재 체계: **필수 20개 + 확장 36개 = 총 56개 항목**

---

## 확장 사유

1. **문서 유형별 고유 정보**: 동의서의 개인정보 수집 목적·보유 기간·제3자 제공 정보, 계약서의 체결일·금액·해지 조건 등은 문서의 핵심 정보이나 원본 항목에 미포함
2. **당사자 상세 정보**: 원본은 저작권자 이름만 정의. 실제 문서에는 전화번호, 주소, 이메일, 사업자등록번호가 함께 기재되어 있어 추출 필요
3. **NER 교차 검증**: NER이 추출한 개체(인명, 전화번호, 주소 등)를 LLM 결과와 대조하여 정확도를 높이려면, LLM 스키마에도 해당 세부 필드가 구조화되어야 함
