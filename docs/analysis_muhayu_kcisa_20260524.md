**Content mix (`분류`, 100% 채움):** 이미지 77,329(54%) · 어문 33,094(23%) · 오디오 26,571(18%) · 영상 5,010(3.5%) · 3D 1,478 · 글꼴 464.

## 3. 붙임2 — 원문DB구축 안내자료 (`붙임2_..._안내자료.pdf`, 7-slide 교육자료)

KCISA의 공공누리 **등록 표준**(이미지 슬라이드).
- **S1** 표지. **S2 썸네일:** 이미지/영상/오디오/3D/어문은 목록·상세 2종 썸네일 필요(글꼴 제외), 카테고리별 px 규격, 72dpi, jpg/png.
- **S3 파일명 일치:** 썸네일 파일명 = 메타데이터 내 파일명 (확장자·대소문자·앞뒤 공백까지 동일).
- **S4 항목등록:** 필수항목(대분류·중분류·게시물명·소장기관·해시태그·유형·원본파일명·용량(KB)·썸네일명). 제작년도=4자리 또는 빈값, 용량=KB단위, 해시태그 쉼표구분.
  - ★ **핵심:** *"권리정보의 경우 **교육대상에서 제외**되며 담당자측과 논의필요"* → **권리정보는 표준 등록절차 밖의 별도 트랙.** (= 데이터에서 권리가 희소한 근본 원인)
- **S5** 유니크 규칙(게시물명·원본파일명·썸네일 중복금지, 셀병합 금지). **S6** 카테고리=시트분리, 기관별 분리 전달 — **예시 파일들이 "○○ 권리정보 메타데이터_完"**(국립극장·세종학당재단·한국보훈진흥원·대한민국역사박물관·국제방송교류재단) → **Stage-2 정답 데이터 출처.** **S7** 폴더구조(기관 > 대분류 > 중분류 > 원본/썸네일).

## 4. KTC + TTA 시험인증요청서 (HWP)

공인시험인증 양식 — 우리 정확도 KPI(속성정보·멀티모달 속성정보 80→85%)의 공식 검증용.
- **KTC(시험결과서):** 품명·분류·**식별자/SHA256 해시값**·HW/SW/OS, 의뢰항목(T-001 성능목표·만족기준), 시험환경(ENV-1)·도구(TL-1~3)·방법, 시험결과.
- **TTA:** 시험신청서(기업/R&D과제정보: 발주부처·과제명·전담기관·기간/제품모델명/시험환경) + 시험기준규격서(TC1: 항목·측정지표·예상결과) + 시험절차서(사전조건·도구·**시험용 데이터**·반복횟수·절차).
- **연결:** KOGL 데이터가 곧 양식이 요구하는 "시험용 데이터(유형별 1,000건)". → 데이터가 모델·인증 모두를 가능케 함.

## 5. Synthesized findings

1. KOGL 데이터 = **카탈로그는 충실, 권리는 별도 트랙이라 희소.** Stage-1/Stage-2 경계가 데이터에 그대로 드러남.
2. 권리정보는 **특정 기관만 완성** → "더 많은 권리데이터"가 아니라 **"공백 기관 권리데이터 + 완성기관의 원본 계약서"**가 정확한 요청.
3. 이 데이터는 우리에게 **대규모 학습/평가셋 + 인증 시험데이터** (8장 한계 해소). 이미지 유형라벨 ~2.9만, 권리완성 ~7.4만.
4. **디지털화형태·해시/UCI**처럼 KOGL이 비운 항목을 우리가 자동 채워 **부가가치** 제공.

## 6. How it's useful (mapping to our work)

- **Stage 1 (카탈로그):** 파일에서 자동 생성 + KOGL 공백(디지털화형태·해시/UCI) 보강. 현재 가능.
- **Stage 2 (권리):** 계약서·동의서 → OCR+LLM+NER. 요청 데이터 확보 후. 정답=완성기관 메타+계약서.
- **학습:** SigLIP 임베딩 기반 **유형 분류기**(2.9만 이미지) + 권리플래그 분류기(상업적이용허락·보호/만료). 속성추출 자체는 VLM zero-shot이라 학습 불필요.
- **평가/인증:** 유형별 균형 표본 → Gemma/Qwen 대규모 평가 → KTC/TTA 정확도 근거.
