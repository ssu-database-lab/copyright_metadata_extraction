## 1. API 개발 현황

현재 **FastAPI** 기반으로 메타데이터 추출 API를 개발하고 있으며, 주요 기능은 아래와 같이 구현되어 있습니다.

| 기능 | 엔드포인트 | 설명 |
|------|-----------|------|
| 통합 추출 | `POST /api/llm-extract` | PDF/이미지 업로드 → OCR + LLM 메타데이터 추출 + NER 엔티티 추출 + 통합 검증까지 전체 파이프라인 수행 |
| OCR 텍스트 추출 | `POST /api/ocr-universal` | PDF/이미지에서 페이지 단위 텍스트 추출 (전체 텍스트 + 페이지별 텍스트) |
| NER 엔티티 추출 | `POST /api/ner-extract` | OCR 텍스트에서 인명, 기관명, 날짜, 연락처 등 엔티티 추출 |
| 파일 업로드 | `POST /upload` | PDF/이미지 업로드 및 NER 기반 메타데이터 추출 |
| 결과 다운로드 | `GET /download/{request_id}` | 추출 결과 JSON/CSV 파일 다운로드 |

API 문서는 서버 실행 후 `/docs` (Swagger UI)에서 확인 가능합니다.

## 2. 시스템 구성 및 모델

현재 시스템은 다음과 같은 모델을 사용합니다:

| 단계 | 모델 | 호스팅 방식 | 비고 |
|------|------|-----------|------|
| **OCR** | Qwen3-VL-235B | Alibaba Cloud API 호출 | API 키 필요 (DashScope) |
| **LLM 메타데이터 추출** | Qwen3-Next-80B | Alibaba Cloud API 호출 | API 키 필요 (DashScope) |
| **통합 검증 (Consolidation)** | Qwen3-Next-80B | Alibaba Cloud API 호출 | LLM + NER 결과 비교 검증 |
| **NER 엔티티 추출** | KLUE-RoBERTa-Large | 로컬 서버 | 경량 모델 (GPU 불필요) |

OCR 및 LLM 추출은 Alibaba Cloud(DashScope)에 호스팅된 모델을 API로 호출하는 방식이며,
NER은 경량 모델이므로 로컬 서버에서 직접 실행됩니다.

## 3. 현재 출력 형식

현재 개발 완료된 메타데이터 추출 항목은 **필수 20개 + 확장 36개 = 총 56개 필드** 기준입니다.

프로젝트 초기에 정의된 **표준 메타데이터 20개 항목**(저작물명, 유형, 저작권자, 공개유형, 저작재산권 등)을 필수 항목으로 유지하면서, 실제 데이터셋의 문서(계약서, 동의서, 양도동의서 등)를 분석하는 과정에서 문서 내 중요 정보를 충분히 추출하기 위해 36개 항목을 확장하였습니다.

| 분류 | 구분 | 항목 수 | 주요 항목 |
|------|------|--------|----------|
| **저작물 정보** | 필수 | 8개 | 저작물명, 유형, 디지털화 형태, 설명, 주제어, 언어, 제작일, 계약서 |
| **저작자 정보** | 필수 | 3개 | 저작권자, 공동저작자, 저작인접권자 |
| **권리 정보** | 필수 | 9개 | 공개유형, 저작물성, 비보호저작물, 업무상저작물, 상업적 이용허락, 저작재산권, 공동저작자 동의, 유효기간, 초상권 |
| **동의서 정보** | 확장 | 14개 | 동의서 유형, 처리자, 정보주체, 수집 목적, 보유 기간, 제3자 제공 정보, 동의 여부 등 |
| **계약서 정보** | 확장 | 11개 | 계약서 유형, 권리자, 이용자, 계약 목적/기간, 체결일, 지급 금액 등 |
| **당사자 정보** | 확장 | 6개 | 전화번호, 주소, 이메일, 역할, 사업자등록번호 |
| **기타 확장** | 확장 | 5개 | 공공누리 유형, 양도 유형/범위, 체크박스 처리 정보 |

> 확장 항목은 원본 20개를 대체하는 것이 아니라 보완하는 것이며, 해당 문서 유형에 관련 정보가 존재할 때만 추출됩니다. 상세 항목별 추출 현황은 별첨 `통합_메타데이터_추출현황.xlsx`를 참조하시기 바랍니다.

## 4. 배포 환경

박명찬 이사님께서 제안하신 **서버에 직접 설치하는 방식**도 가능합니다.
FastAPI는 원격 API 서비스 또는 서버 직접 설치 방식 모두 지원합니다.

현재 OCR(Qwen3-VL) 및 LLM 메타데이터 추출(Qwen3-Next-80B)은 **Alibaba Cloud DashScope API**를 통해 호출하고 있으며, 프로토타입 단계에서는 이 방식으로 진행할 예정입니다.

### 4.2 필요 사항

프로토타입 배포를 위해 아래 사항에 대한 확인이 필요합니다:

1. **FastAPI 호스팅 서버**: 현재 API는 FastAPI 서버 위에서 동작합니다. 프로토타입 운영을 위한 서버가 제공될 예정인지 확인 부탁드립니다. (예: 무하유 또는 HM컴퍼니 측 서버, 클라우드 인스턴스 등)
