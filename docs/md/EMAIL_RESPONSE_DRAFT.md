### 1. 프로토타입 수준 API 개발 현황

**현재 개발된 상태 기준으로 프로토타입 수준의 API가 존재합니다.**

- **주요 기능**: 저작물(계약서·동의서 등) 업로드 시 **메타데이터 추출** 및 **자동 분류**
- **구현 완료 항목**:
  - PDF/이미지 업로드 및 OCR 텍스트 추출 (Google, Naver, Mistral, Alibaba Cloud 지원)
  - LLM 기반 구조화된 메타데이터 추출 (계약서, 동의서, 기타문서 등 문서 유형별 스키마 적용)
  - NER(개체명 인식) 엔티티 추출 (인명, 날짜, 전화번호, 회사명 등)
  - LLM 결과와 NER 결과를 비교·통합하여 최종 메타데이터 생성 (Consolidation Agent)
  - 문서 유형 자동 감지 및 맞춤 스키마 적용

---

### 2. API 명세서 제공 가능 여부

**외부 공유 가능한 API 명세서를 작성해 두었습니다.**

- **문서명**: `API_SPECIFICATION.md` (프로젝트 루트에 위치)
- **포함 내용**:
  - API 엔드포인트 목록 및 상세 명세
  - 요청/응답 형식 (파라미터, JSON 구조)
  - 지원 문서 유형 및 메타데이터 스키마 개요
  - 기술 스택 및 프로토타입 범위/제한사항

- **핵심 API**:
  - `POST /api/llm-extract`: 저작물 업로드 → 메타데이터 추출·분류 (통합 엔드포인트)
  - `POST /api/ner-extract`: NER 엔티티 추출 전용
  - `POST /api/ocr-universal`: OCR 텍스트 추출 전용
  - `GET /download/{request_id}`: 결과 파일 다운로드

- **자동 API 문서**: FastAPI 기반으로 `/docs`(Swagger UI), `/redoc`에서 인터랙티브 문서 제공

---

### 3. 프로토타입 범위 및 수준

- **현재 수준**: 연구·시범용 프로토타입
- **외부 접근**: API는 **현재 외부에서 접근할 수 없으며**, 모든 테스트는 **로컬 환경**에서 수행되었습니다.
- **웹 인터페이스**: API 엔드포인트 테스트를 위한 **웹 UI**를 함께 구현해 두었습니다. (파일 업로드, 옵션 선택, 결과 확인 등)
- **인증/보안**: API 키·토큰 기반 인증 미구현 (내부 테스트용)
- **배포 환경**: 로컬 또는 내부 서버 실행 기준
- **프로토타입 범위 및 수준**: 말씀하신 바와 같이 **추후 협의 가능**합니다.
