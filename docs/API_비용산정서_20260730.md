## 4. 비용 산정식 ★ (본 문서의 핵심)

비용은 **페이지 수와 문서 건수 두 변수**에 의해 결정됩니다. OCR은 페이지마다 발생하지만, 추출·통합검증은 **문서 1건당 1회만** 발생합니다.

> ### 비용 = **₩3.05 × 페이지 수** + **₩44.8 × 문서 건수**
>
> - **₩3.05/페이지** = OCR 호출 ₩2.7 + 추출 프롬프트 증가분 ₩0.35
> - **₩44.8/문서** = 통합검증 ₩34.6 + 추출 고정분 ₩10.2

**검증:** 실측한 4페이지 문서 1건 = 실제 $0.04069 / 산정식 $0.04073 → **오차 0.1%**

### 페이지 수만으로 산정할 수 없는 이유

문서 1건당 고정비(₩44.8)가 페이지당 비용(₩3.05)의 **약 15배**입니다. 따라서 동일한 페이지 수라도 문서 건수에 따라 비용이 크게 달라집니다.

| 동일한 100페이지, 문서 구성만 다름 | 비용 |
|---|---|
| 100페이지 = 1개 문서 | ₩362 |
| 100페이지 = 10개 문서(각 10p) | ₩753 |
| 100페이지 = 100개 문서(각 1p) | **₩4,788** |

→ **페이지 수는 같지만 비용은 13배 차이.** 반드시 문서 건수를 함께 제시해야 합니다.
