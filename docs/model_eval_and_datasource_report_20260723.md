## 3. OCR 실측 테스트 (실제 스캔 계약서)

- **테스트 문서:** `data/pdf/계약서/20251110_133106_992874/샘플_저작물..._7.저작물양도계약서.pdf` (4쪽, 텍스트레이어 없는 스캔, 200 DPI 렌더).
- **채점:** 1쪽을 사람이 직접 전사한 GROUND TRUTH 대비 문자 유사도(difflib) + 앵커 15개(제목·날짜·기관명·㈜기호·주소 등) 재현율 + 지연.

| 모델 | 문자 정확도 | 앵커 | 지연/쪽 | 특이 |
|---|---|---|---|---|
| qwen3-vl-235b (현행) | 97.8% | 14/15 | 13s | `㈜` 기호 누락 |
| **qwen3.6-plus** | **98.7%** | **15/15** | 24s | 최고 정확도(㈜ 인식) |
| **qwen3.6-35b-a3b** | 97.8% | 14/15 | **5s** | **현행과 동일 정확도 · 2.6× 빠름** |
| qwen3.7-plus | 98.1% | 15/15 | 58s | 정확하나 대량 처리엔 과도하게 느림 |

**결론:** 깨끗한 인쇄 한국어 계약서에서는 4종 모두 우수(~98%), 차이는 미미. `㈜` 법인기호가 유일한 변별점(3.6-plus·3.7-plus만 정확). **qwen3.6-35b-a3b가 현행과 같은 정확도에 훨씬 빠르고 싸다** → 144K 대량 OCR에 유리.

**⚠ 한계(중요):** 위는 **깨끗한 인쇄 1쪽**만의 결과. qwen3-vl-235b가 "특화 모델"인 이유는 **열화 입력**(저조도·블러·기울기·도장·손글씨·복잡 표) 로버스트니스. 이 테스트는 그걸 검증하지 못함. **교체 전 반드시 열화/손글씨 스캔 세트로 재검증 필요.**

- 산출물: `<scratch>/ocrtest/` (렌더 이미지 + 각 모델 OCR 출력 `ocr_outputs.json`).

## 4. 이미지 설명(VLM) 품질 테스트

- **테스트:** KOGL 골드 이미지 2건(수원화성·아침고요수목원)에 3~4문장 한국어 설명 생성 → GOLD(대상 배경설명) 기준 subject-consistency + descriptive-quality 를 qwen-max 심판으로 1–5 채점.

| 모델 | subject(1-5) | quality(1-5) | 지연 |
|---|---|---|---|
| qwen3-vl-235b (현행) | 1.5 | 4.5 | 4s |
| qwen3.6-plus | 2.0 | 5.0 | 6s |
| qwen3.7-plus | 2.5 | 4.0 | 17s |
| qwen3.6-35b-a3b | 2.5 | 4.0 | 4s |
| **Gemma 4 31B (현 primary)** | **정확** | 높음 | (OpenRouter) |

**핵심 발견:** **모든 Qwen 계열(현행 qwen3-vl 포함)이 한국 전통 한옥을 '일본식 건물'로 오인**. **Gemma 4 만 '한국식 가옥'으로 정확히 인식.** → 이미지 속성 추출에서 **Gemma primary 유지가 정당**함을 재확인. Qwen 폴백은 qwen3.6-35b-a3b(빠름·저가·동급)로 교체 가능.

## 5. 텍스트 모델 (웹 벤치마크 조사 + 비용)

> ⚠ **신뢰도 경고:** Qwen3.6/3.7·GLM-5.2 수치는 전부 3rd-party이며 공식 교차검증이 부분 실패(Qwen3.6 공식 블로그 게시물 부재, 소스 간 출시일·컨텍스트·지능지수 모순). **한국어 전용 벤치·IFEval·JSON 신뢰성 공개수치는 사실상 없음.** 아래는 방향성 참고 — 확정 인용 금지, 자체 A/B 실측으로 확정 권장.

**웹 조사 요지:**
- qwen3.7-max = 현 Qwen **텍스트 플래그십**(GPQA 92.4, 멀티링구얼 WMT24++ 85.8 #1). **텍스트 전용.**
- qwen3.7-plus = **IFEval 94.6 (max 94.3보다 근소 우위)**, 추론 근접, **출력비용 약 절반**. 멀티모달.
- qwen3.6-max-preview = 코딩 특화(6개 코딩 벤치 1위), 종합은 3.7-max에 뒤짐. **preview = 프로덕션 금지**(비재현성·강제 마이그레이션).
- GLM-5.2 = MIT 오픈웨이트·셀프호스트 가능, 지능 최상위지만 **멀티링구얼 열세(83.1 vs Qwen 87)** → 한국어 작업 2순위, PII 온프렘 요구 시만.
- **추출 유지 근거:** Qwen3.5 계열이 Structured Output value-accuracy 오픈 **1위(0.801)**. "Invalid JSON"의 원인은 모델이 아니라 schema-constrained decoding 미적용.

**비용(≈144K 저작물 1회 완주, 텍스트 레그만; 문서당 입력~12K·출력~5K tok 가정):**

|---|---|---|---|---|
| qwen3.6-flash | 0.25 | 1.50 | ~$1,512 | −50% |
| **qwen3.7-plus** | 0.40 | **1.60** | **~$1,843** | **−38%** |
| qwen3.6-35b-a3b | 0.375 | 2.25 | ~$2,268 | −24% |
| **qwen3.5-122b-a10b (현재)** | 0.40 | 3.20 | **~$2,995** | 기준 |
| qwen3.6-plus | 0.50 | 3.00 | ~$3,024 | +1% |
| qwen3.7-max (할인가) | 1.25 | 3.75 | ~$4,860 | +62% (할인종료 시 +224%) |
| glm-5.2 | 1.40 | 4.40 | ~$5,587 | +87% |
| qwen3.6-max-preview | 1.30 | 7.80 | ~$7,862 | +163% |

- 우리 워크로드는 **출력(JSON+한국어 근거) 비중이 커** 출력단가가 총비용 지배 → qwen3.7-plus 출력 −50%가 결정적.
- Rate limit: plus 15,000 RPM / 5M TPM ≫ max 600 RPM / 1M TPM → **대량 처리엔 plus가 유리**.
- **미완:** 자체 계약서 데이터로 5개 모델(3.5-122b / 3.6-35b-a3b / 3.6-plus / 3.6-max-preview / 3.7-max) A/B 추출 벤치를 시작했으나 reasoning 모델 지연/rate-limit로 **완료 못함** → §9 후속.

- 참고 파일: 워크플로 결과 `<session>/tasks/wih1c6pz6.output` (4개 조사 에이전트 + 종합 판정, 근거 URL·수치 포함).

## 6. GOLD 설명 데이터소스 조사

**목표:** 이미지에 대한 "정답(GOLD) 설명" 을 확보해 VLM(Gemma/Qwen) 설명 품질을 평가.

### 6.1 우리 export/manifest에는 설명이 없다
- `docs/붙임1_원문저작물 메타데이터.xlsx`(144K, 75열): **설명 컬럼 없음.** 유일한 산문 컬럼 `공공저작물활용안내`도 8%만 채워짐. 나머지는 짧은 태그(주제어·해시태그).
- 우리 `dataset/manifest.xlsx`(1,500건): **저작물 설명 ~93% 빈값('-')**. (박물관 유물·역사사진은 설명 없이 등록됨.)

### 6.2 KOGL 상세페이지에는 `저작물 설명` 이 있다 (export엔 없는 필드)
- KOGL 웹 상세페이지 `recommend/recommendDivView.do?recommendIdx=N&division=img` 의 **모달 `저작물 설명`** 필드에 실제 설명 존재. **익명 접근 가능(로그인 불필요).**
- 대표 이미지도 `/upload_recommend/...jpg` 에서 **익명 다운로드 가능(~700px)**.
- 설명이 풍부한 것은 **관광·문화재·지자체 계열**(수원화성 2,313자, 아침고요수목원 1,469자). 박물관 유물은 대체로 빈값.
- ★ 각 recommendIdx = 하나의 설명을 공유하는 **갤러리**(여러 이미지) → 대표 1장만 취함.

### 6.3 공유마당(gongu.copyright.or.kr) — 별도 신규 소스
- 익명 다운로드 검증 완료. 상세: **`docs/gongu_download_research_20260720.md`** + 다운로더 `api/module/dataset_builder/gongu_downloader.py`.
- 요약: 이미지 139만·영상 12.8만건, `licenseCd=97`=만료(퍼블릭도메인). CCL(21/24) 계열이 파일+설명 동시 확보 스위트스팟. AI 원천데이터 게시판 = 7.25M건 신청형.

### 6.4 확보한 GOLD 세트 (완료)
- 워크플로로 관광/문화재/자연 테마 **79건 후보** 수집 → 스크레이퍼로 필터(설명≥80자·중복제거·이미지 다운로드 성공) → **최종 72건 확정**.
- 위치: **`dataset/kogl_gold/kogl_gold.xlsx`** (+ `images/*.jpg` 72장). 설명 길이 median 321자, 범위 88–3,028자.
- 예: 전주한옥마을·은평한옥마을·곡성세계장미축제·목포해상케이블카·서산 개심사·구례 수락폭포 등.

### 6.5 ⚠ 방법론 핵심 발견: KOGL GOLD는 '캡션'이 아니라 '배경 에세이'
- KOGL `저작물 설명`은 **대상의 역사·관광 배경 설명**이지 사진의 시각 캡션이 아님. (수원화성 → 조선 태종·정조 효심 서술; 사진 = 눈 덮인 성곽 야경.)
- 따라서 VLM의 (정확한) 시각 설명을 이 에세이와 **정확 일치로 채점하면 무의미(초기 1/5)**. → 평가 루브릭을 **subject-consistency(대상부합) + descriptive-quality(서술품질)** 로 재설계함(에세이 재현이 아니라 대상 부합·오류 여부로 채점). 이 루브릭이 §4의 '일본식 오인' 같은 실오류를 정확히 잡아냄.
- 참고: 진짜 이미지-캡션 GOLD는 **AI-Hub 한국어 이미지 설명(dataSetSn=261)** 이 유일하나 내국인 승인 게이트. 대안 리치소스 = 국가유산포털 OpenAPI.

## 8. 결론 & 권고 (실행 관점)

1. **OCR:** 현행 `qwen3-vl-235b-instruct` 유지가 안전. 단 `qwen3.6-35b-a3b`가 동급 정확도·2.6× 속도 → **열화 스캔 로버스트니스 테스트 통과 시 교체**(대량 비용/처리량 이득).
2. **추출:** `qwen3.5-122b-a10b` 유지. 진짜 개선은 모델 교체가 아니라 **schema-constrained decoding + 값검증**(Invalid JSON 근절). 비용 목적이면 qwen3.7-plus 파일럿.
3. **통합/중재:** 교체 가치가 가장 큼 → **qwen3.7-plus 파일럿**(품질 동등↑ 예상 + 출력비용 −38%). qwen3.7-max는 고난도 중재 품질이 실측으로 정당화될 때만 통합 레그 한정.
4. **이미지 속성(VLM):** **Gemma 4 primary 유지 확정**(유일하게 한옥 정확 인식). Qwen 폴백은 qwen3.6-35b-a3b로 교체 가능.
5. **플래그십 오해 정정:** qwen3.7-max·qwen3.6-max-preview는 **텍스트 전용** → OCR/VLM 교체 후보 아님. `-preview`는 프로덕션 금지.
