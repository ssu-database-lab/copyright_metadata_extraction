API 명세서 → HWP 변환 방법
============================

생성된 파일: API_SPECIFICATION.docx

HWP 파일로 변환하려면:

1. API_SPECIFICATION.docx를 한글과컴퓨터 한글(Hancom Office)에서 엽니다.
2. 메뉴: 파일 → 다른 이름으로 저장
3. 파일 형식에서 "한글 문서 (*.hwp)" 선택
4. 저장

※ Microsoft Word가 있다면 Word에서도 열 수 있으며,
   한글이 설치되어 있으면 Word에서 "다른 이름으로 저장" 시 HWP 형식이 표시될 수 있습니다.
