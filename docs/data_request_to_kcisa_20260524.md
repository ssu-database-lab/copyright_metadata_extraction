# 데이터 요청서 (한국문화정보원 전달용)

> 장세영 연구원님께서 5/26 회의 또는 무하유를 통해 한국문화정보원(KCISA)에 전달하실 수 있도록 정리한 메시지입니다. 그대로 복사하여 사용하시거나 일부 발췌하셔도 됩니다.

---

안녕하세요. 숭실대학교 산학협력단입니다.

먼저 공공누리 원문저작물 메타데이터(143,946건, 75개 항목)를 공유해 주셔서 감사합니다. 전체 데이터를 분석한 결과를 간략히 공유드리고, 2단계(권리정보 포함 신뢰성 강화 메타데이터) 자동 생성을 위해 추가로 필요한 데이터를 요청드립니다.

## 분석 요약

- **카탈로그(목록) 메타데이터는 충실히 채워져 있어** 1단계(원문DB 등록용 업로드 메타데이터) 표준화·자동 생성은 현재 데이터로 가능합니다. (제목·분류·소장기관·해시태그·게시글URL 등 약 100%)
- 다만 **권리정보 항목은 채움률이 낮습니다.** 핵심 권리 항목(저작권자명·각 저작재산권 등)은 약 51%, 권리 출처 항목(저작권자 소속 17%, 공동저작자 20%, 저작인접권자 17%, 계약상 유효기간 14%, 초상권 14%)은 더 낮으며, **디지털화 형태·저작권기관명·UCI·해시·버전 항목은 사실상 비어 있습니다.**
- **권리정보는 행 단위로 '전부 채움 또는 전부 빔'**이며(73,760건 완성 / 약 70,000건 공백), **기관(원본소유자)별로 완성 여부가 갈립니다.**
  - 권리정보 완성(약 100%): 한국문화예술교육진흥원·세종학당재단·한국학중앙연구원·진주시·광진구·국립대전현충원·제주콘텐츠진흥원·국제방송교류재단 등
  - 권리정보 공백(0%): 제주특별자치도·국가유산청·국립국악원·한국문화정보원(자체)·인천광역시·부산광역시·한국농수산식품유통공사 등
- 안내자료(원문DB구축 교육자료)에도 *"권리정보의 경우 교육대상에서 제외되며 담당자측과 논의 필요"*로 명시되어 있어, 권리정보가 표준 등록 절차 밖의 별도 트랙임을 확인했습니다.

## 추가 요청 데이터 (우선순위 순)

1. **원본 저작물 파일 샘플 (최우선)**
   - 이미지·오디오·영상·문서 원본 파일 일괄 샘플(유형별 수백~수천 건).
   - 게시글URL·원본파일경로는 확보되어 있으나, 멀티모달 AI 분석 및 식별자(SHA256/UCI) 생성을 위해 **실제 파일 접근**이 필요합니다. (대량 다운로드 또는 NAS 접근 경로)

2. **권리정보 공백 기관의 「권리정보 메타데이터_完」 파일**
   - 전달받은 데이터 분석 결과, 권리정보는 **이미 일부 기관(한국문화예술교육진흥원·세종학당재단·한국학중앙연구원 등)만 완성**되어 있고, **제주특별자치도·국가유산청·국립국악원·한국문화정보원 등 다수 기관은 0%**입니다.
   - 따라서 **아직 권리정보가 채워지지 않은 기관들의 권리정보 메타데이터_完 파일**(안내자료 슬라이드6 형식)을 추가로 요청드립니다. 2단계 권리정보 추정 모델의 학습·검증 범위를 넓히기 위함입니다.

3. **원본 저작물 ↔ 계약서/동의서 매핑 샘플 (이미 완성된 기관 우선)**
   - **권리정보가 완성된 기관**(예: 세종학당재단·한국학중앙연구원)의 저작물에 대해, 해당 권리정보의 **출처가 된 실제 계약서·양도동의서 원문**과 저작물의 매핑 샘플.
   - "계약서 → 권리정보(저작권자·공동저작자·인접권자·유효기간·권리근거)"의 변환 규칙을 학습/검증하기 위함입니다. (완성 메타데이터 + 원본 계약서가 한 세트로 있으면 정답쌍으로 가장 유용)

4. **분류표(대/중/소분류 코드표)**
   - 데이터의 대분류코드·중분류코드·소분류코드를 해석할 수 있는 코드북. (안내자료에 "별도 전달하는 분류표 참조"로 언급됨)

5. **권리정보 입력 기준/규칙 확인**
   - 권리정보 항목값(KOGL 공개유형·권리근거·유효기간·제3자 권리 여부 등)을 **어떤 기준으로 판단·입력하는지** 담당자 가이드.
   - 자동화 로직이 따라야 할 판단 기준을 정의하기 위함입니다.

위 데이터가 확보되면 1단계 자동 생성은 즉시 고도화 가능하며, 2단계 권리정보 추정 모델 개발 및 공인시험인증(정확도 검증)을 본격 진행할 수 있습니다.

감사합니다.
숭실대학교 산학협력단 드림
