## 슬라이드 7 — ② 스키마 확장 72 → 86필드 (증거: 코드)

**왜 필요했나**: 기존 스키마는 법적으로 다른 네 지위를 `copyright_holder` 하나에 뭉쳐 두었다
— 설명문이 *"저작권자 (저작권 보유자, 권리자, 양수기관 등)"*.

실측: 권리자 = 저작자 **71%**, 저작자 = 저작권자명 **68%**, 셋 모두 일치 **51%**. 교환 가능한 값이 아니다.

```python
# 추가된 권리주체 — TTA 4.1 / 4.3 / 4.4 / 4.6
"author":                   "저작자 (저작물을 창작한 자)"
"economic_rights_holder":   "저작재산권자"
"licensor":                 "이용허락자"
"rights_holder_identifier": "권리주체 식별자"   # 생년월일·주민번호는 식별자가 아님

# 추가된 저작재산권 세부 권리 — TTA 7.1~7.7 (계약서 제2조 체크박스)
"reproduction_right" … "derivative_work_creation_right"   # 7개 boolean

# 추가된 유효기간 — TTA 8.2 / 8.3
"license_start_date", "license_end_date"
```

**설계 판단: 추출은 평면 유지, 출력 직전에 중첩으로 접는다**
— 추출 자체를 중첩시키면 통합·NER 매핑·채점이 모두 경로 기반으로 바뀐다.
**실측 근거: 이름 대응표 없이 중첩만 시키면 채점이 0.483 → 0.000 으로 붕괴한다.**

## 슬라이드 10 — ④ 찾아낸 결함 (발표 핵심: "왜 흔들렸는가")

동일 ZIP 을 반복 실행했을 때 세트 점수가 **92.9% ~ 0.0%** 로 흔들렸다. 원인은 하나가 아니라 넷이었다.

| # | 결함 | 증상 | 상태 |
|---|---|---|---|
| 1 | **상속 목록 누락** — 신규 14필드가 계약서→저작물 상속 목록에 없었음 | 모델이 세분 필드를 채운 호출에서만 0점 | ✅ 수정 |
| 2 | **통합 단계 필드 손실** — 성공을 보고하며 44필드→3필드 | 멀쩡한 추출이 버려짐 | ✅ 방어 + 진단 계측 |
| 3 | **DashScope 입력검열 오탐** | 1회 거부 → 세트 13/14 → 1/14 | ✅ 재시도 |
| 4 | **표시 계층 11속성 하드코딩 4곳** | 모달 빈칸·11항목 | ✅ 수정 |

**#1 이 진짜 원인이었다.** `granted_rights`(뭉뚱그린 필드)는 상속되고 개별 권리 7종은 상속되지
않아, 모델이 어느 모양으로 답하느냐에 따라 같은 세트가 100% 또는 0% 가 됐다.

> 정직하게 밝힐 점: 먼저 넣었던 채점기 폴백이 **이 문제를 가리고 있었다**. 뭉뚱그린 필드를
> 채점 가능하게 만들어 증상만 사라졌고, 세분 필드가 버려지는 사실은 드러나지 않았다.

## 슬라이드 11 — ④ 통합(중재) 단계 계측 (증거: 코드 + 수치)

통합이 성공을 보고하면서 필드를 잃는 사례가 **최근 60건 중 9건**. 원인 규명이 안 된 이유는
**중재자 원문 응답을 저장하지 않았기 때문**이다. 이번 주에 계측을 넣었다.

```python
# 중재 전후를 나란히 남긴다 — 손실이 있으면 원문 응답까지 보관
diag = {
    "consolidation_fields_before": before,     # 예: 44
    "consolidation_fields_after":  after,      # 예: 3
    "consolidation_lost_fields":   lost,       # 잃은 필드 이름 목록
}
if lost:                                       # 손실 시에만 원문 보관
    diag["consolidation_raw_response"] = ...
    diag["consolidation_prompt_chars"] = ...
```

**계측 후 19세트 실행 결과: 통합 38건 전수, 손실 0건**
이전에 손실이 있었던 2건(13002399, 13266643)을 고정 포함시켜 재실행 — 각각 **100.0% / 92.9%**

> 정직하게 밝힐 점: 38건 무손실은 고무적이지만 **수정이 통했다는 증명은 아니다**.
> 손실은 원래 간헐적이었고, 38건은 "운이 좋았다" 와도 양립한다. 확보한 것은 **다음 손실을
> 원문과 함께 포착할 수 있는 계측**이다.
